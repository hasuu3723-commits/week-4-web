
# SpendWise Dashboard Shell

## Project Description

SpendWise is a modern personal finance dashboard designed to help users visualize and organize their financial information.

The dashboard displays financial summaries, spending categories, and recent transactions using a clean and responsive interface.

This project focuses on CSS Grid, Flexbox, CSS Custom Properties, responsive design, and interactive visual effects.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Google Fonts

## Main Features

### 1. Sidebar Navigation
The sidebar contains navigation links for:
- Dashboard
- Transactions
- Budget
- Reports
- Settings

### 2. Dashboard Header
The header displays the dashboard title, welcome message, notification icon, and user profile.

### 3. Financial Summary
Three summary cards display:
- Total Balance
- Monthly Income
- Monthly Expenses

### 4. Spending Categories
The dashboard contains six category cards:

- Food
- Transport
- Rent
- Entertainment
- Savings
- Utilities

Each card displays static financial information and a progress bar.

### 5. Recent Activity
The recent activity section displays sample financial transactions.

## CSS Concepts Applied

### CSS Grid
Grid is used to organize the overall dashboard layout, summary cards, and spending category cards.

### Flexbox
Flexbox is used to arrange sidebar navigation items, header content, profiles, and individual card content.

### CSS Custom Properties
CSS variables are defined inside the :root selector to maintain a consistent color theme.

### Responsive Design
A media query below 768px changes the dashboard into a single-column layout for smaller screens.

### Micro-interactions
Dashboard cards use hover and keyboard focus effects with transitions lasting 200 milliseconds.

### Dark Theme
A dark theme is supported using the prefers-color-scheme media query and CSS custom properties.

## Project Files

- index.html: Contains the dashboard structure and static financial content.
- style.css: Contains the layout, colors, typography, responsive design, and visual effects.
- README.md: Explains the project and the technologies used.

## Conclusion

SpendWise demonstrates how CSS Grid and Flexbox can be combined to create a modern, responsive dashboard.

The project provides the visual foundation for a future personal finance capstone application.
